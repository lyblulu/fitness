## 2. 技术栈说明

- **前端框架**：React@18 + TypeScript + Vite
- **样式方案**：TailwindCSS@3，配合自定义 CSS 变量实现主题
- **路由方案**：React Router v6，实现页面间导航
- **数据管理**：本地 JSON 数据 + React Context，无需后端服务
- **初始化工具**：Vite（create-vite）
- **构建部署**：Vite 构建，可部署到任意静态托管平台

## 3. 路由定义

| 路由 | 页面 | 说明 |
|------|------|------|
| / | 首页 | 网站首页，展示训练和营养概览 |
| /training | 训练计划页 | 三分化/四分化训练详细方案 |
| /nutrition | 营养饮食页 | 一日三餐营养分配方案 |
| /article/:id | 文章详情页 | 单篇文章详细阅读 |

## 5. 数据模型

### 5.1 训练数据

```typescript
interface Exercise {
  name: string;
  sets: number;
  reps: string;
  notes?: string;
}

interface TrainingDay {
  dayName: string;
  bodyParts: string[];
  exercises: Exercise[];
}

interface SplitPlan {
  type: '三分化' | '四分化';
  days: TrainingDay[];
}

interface BodyPartExercise {
  bodyPart: string;
  exercises: Exercise[];
}
```

### 5.2 营养数据

```typescript
interface Meal {
  meal: string;
  carbs: number;
  protein: number;
  fat: number;
  foodExamples: string[];
}

interface NutritionPlan {
  totalCalories: number;
  meals: Meal[];
}
```

### 5.3 文章数据

```typescript
interface Article {
  id: number;
  title: string;
  excerpt: string;
  content: string;
  category: 'training' | 'nutrition';
  tags: string[];
  date: string;
  image: string;
}
```
