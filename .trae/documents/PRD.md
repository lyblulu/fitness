## 1. 产品概述

一个专注于力量训练和健身营养的博客分享网站，帮助健身爱好者了解三分化/四分化训练计划，以及科学的一日三餐营养分配方案。

- 目标用户：健身初学者和进阶训练者，希望获得系统化训练计划和饮食指导的人群
- 核心价值：提供清晰、可执行的训练分化方案和营养搭配指南，打造专业的健身知识分享平台

## 2. 核心功能

### 2.1 功能模块

1. **首页**：品牌形象展示、训练哲学介绍、内容导航
2. **训练计划页**：三分化/四分化训练详解，涵盖胸、肩、背、腹、肱二头、肱三头、腿部等部位的系统训练方案
3. **营养饮食页**：一日三餐的碳水、蛋白质分配指南，饮食计划示例
4. **文章详情页**：单篇博客文章详细阅读页面

## 4. 用户界面设计

### 4.1 设计风格

- **设计基调**：力量感 + 现代简约，暗色为主色调，营造健身房般的专注和力量氛围
- **主色调**：深色背景（#0a0a0a 到 #1a1a1a），搭配活力橙红色（#ff4d00）作为强调色，象征力量与激情
- **辅助色**：暖灰色（#e0d6c8）用于正文文字，柔和的暗金色（#c9a84c）用于点缀
- **按钮风格**：圆角矩形，强调色填充，hover 时亮度变化
- **字体**：标题使用粗犷有力的字体（如 Bebas Neue 或 Anton），正文使用清晰易读的字体（如 Source Sans Pro）
- **布局风格**：卡片式布局，大间距呼吸感，图片与文字交错排列

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 首页 | 英雄区 | 全屏大标题 + 渐变背景，粗体大字，号召性按钮 |
| 首页 | 训练概览 | 两张训练卡片（三分化/四分化），悬停动效，图标装饰 |
| 首页 | 营养概览 | 营养卡片展示，配食物图标 |
| 首页 | 最新文章 | 文章卡片网格，3列布局，每张卡片含标题、摘要、日期 |
| 训练计划页 | 训练哲学 | 引言区域，加引号样式 |
| 训练计划页 | 三分化训练 | 推/拉/腿三列卡片，每列列出动作列表 |
| 训练计划页 | 四分化训练 | 四列卡片布局 |

| 文章详情页 | 文章内容 | 正文排版，图片嵌入，引用样式 |
| 文章详情页 | 相关推荐 | 底部相关文章水平滚动 |

### 4.3 响应式设计

- 桌面优先设计，适配平板和手机端
- 桌面端（>1024px）：多列布局，大间距
- 平板端（768-1024px）：两列布局
- 手机端（<768px）：单列布局，汉堡菜单导航

## 5. 数据模型

### 5.1 文章数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 文章唯一标识 |
| title | string | 文章标题 |
| excerpt | string | 文章摘要 |
| content | string | 文章正文（Markdown） |
| category | string | 分类（训练/营养） |
| tags | string[] | 标签列表 |
| date | string | 发布日期 |
| image | string | 封面图片URL |

### 5.2 训练数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 训练条目唯一标识 |
| splitType | string | 分化类型（三分化/四分化） |
| dayName | string | 训练日名称（如"推日"） |
| bodyParts | string[] | 训练部位列表 |
| exercises | Exercise[] | 训练动作列表（名称、组数、次数） |

### 5.3 营养数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| meal | string | 餐次（早餐/午餐/晚餐） |
| carbs | number | 碳水克数 |
| protein | number | 蛋白质克数 |
| fat | number | 脂肪克数 |
| foodExamples | string[] | 食物示例列表 |
